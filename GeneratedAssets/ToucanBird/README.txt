Toucan Sprite Sheet

File: toucan-spritesheet.png
Format: RGBA PNG with transparent background
Sheet size: 64 x 16 pixels
Layout: 4 frames in one horizontal row
Frame size: 16 x 16 pixels
Direction: Facing right

Recommended Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Pixels Per Unit: 16
- Filter Mode: Point (no filter)
- Compression: None

In the Sprite Editor, slice as a 16 x 16 grid. Play the four frames
