# academit-flappy-bird

Flappy Bird clone built in Unity.

## Getting started

1. Open the project folder in Unity Hub.
2. Open the main scene under `Assets/Scenes`.
3. Press Play.

## Structure

- `Assets/Scripts` - gameplay code (bird control, pipes, scoring, UI, audio).
- `CONVENTIONS.md` - C# coding conventions for this project, I took from an earlier C# course I had.

## Controls

Space / left click / tap to flap.
